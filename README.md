# Actione

### One gesture. Any action.

**Actione** is a Windows desktop application designed to bring common file actions into one radial menu.

Download the latest version and try it on your Windows PC.

## Download Actione

**[Download Actione v0.1.0 for Windows x64](https://github.com/Debihub/Actione-Downloads/releases/latest)**

The download is provided as a ZIP package.

## Installation

1. Open the [latest release](https://github.com/Debihub/Actione-Downloads/releases/latest).
2. Under **Assets**, download `Actione-0.1.0-win-x64.zip`.
3. Extract the ZIP into a folder on your PC.
4. Open the extracted folder.
5. Double-click `ActioneMVP.exe` to launch Actione.

**Important:** Keep all files from the extracted ZIP together. Do not move the EXE away from its supporting files.

## System Requirements

- Windows x64
- A compatible Windows environment for the included application package

The application has not yet been verified on every Windows configuration.
